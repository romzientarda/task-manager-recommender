# Подбор приложения для управления задачами

В архиве находится готовый статический сайт для подбора приложения по потребностям пользователя.

## Что изменено в этой версии

- Главная страница стала более пользовательской: убраны лишние технические пояснения, бейджи и матрица критериев.
- Название изменено на «Подбор приложения для управления задачами».
- В вопросах больше нет подписи «Критерий: ...».
- На этапе интерфейса показывается короткий вопрос: «Какой интерфейс Вам больше нравится?».
- В итоговых рекомендациях не указано, выбрал пользователь приложение вручную или оно было добавлено автоматически.
- Процент совпадения снова отображается в карточках результата.
- Блоки «Что хорошо подходит» и «Что лучше проверить» оформлены спокойными цветами.

## Как открыть сайт

Откройте файл `index.html` в браузере.

## Структура файлов

- `index.html` — разметка сайта;
- `styles.css` — оформление;
- `app.js` — данные приложений и логика подбора;
- `assets/screenshots/` — изображения интерфейсов приложений.


Обновление v7: подпись «Учитывается:» убрана из вопросов, а рабочая зона опроса и выбора интерфейса центрируется на экране для более удобного прохождения.

Обновление v8: сайт адаптирован под смартфоны. Используется один и тот же `index.html`, а внешний вид для телефона меняется через CSS-медиазапросы. Отдельная мобильная HTML-страница не нужна.

## Размещение на GitHub Pages

Для публикации достаточно загрузить в репозиторий все файлы и папку `assets`, затем включить GitHub Pages для ветки `main` или `master`. Главная страница должна называться `index.html`.


## Обновление v9

- Добавлены реальные скриншоты интерфейсов для всех 14 приложений.
- Автопрокрутка при переходе между этапами отключена, поэтому страница больше не перемещается сама.
